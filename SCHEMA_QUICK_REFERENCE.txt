VALUATION RESULTS (What we calculate):
  valuations.blended_low_range         → Min estimate ($)
  valuations.blended_high_range        → Max estimate ($)
  valuations.blended_weighted_average  → Best estimate ($)
  valuations.confidence_level          → 'low' | 'medium' | 'high'
  valuations.data_completeness         → 0-100 (%)

COMPANY METRICS (What we analyze):
  startups.arr                         → Annual Recurring Revenue
  startups.monthly_growth_rate         → % per month
  startups.customer_count              → Number of customers
  startups.team_size                   → Total team
  startups.industry                    → SaaS, AI/ML, FinTech, etc.
  startups.stage                       → pre-revenue | seed | series-a | series-b+

VALUATION METHODS (6 Methods):
  valuation_methods.method_name        → 'scorecard' | 'berkus' | 'vcMethod' | 'dcfLTG' | 'dcfMultiples' | 'evaldam-score'
  valuation_methods.low_estimate       → Low $ estimate
  valuation_methods.mid_estimate       → Mid $ estimate
  valuation_methods.high_estimate      → High $ estimate
  valuation_methods.assumptions        → JSONB - method assumptions
  valuation_methods.benchmarks_used    → JSONB - market benchmarks

SUBSCRIPTION (How users pay):
  users.plan                           → 'pro' | 'plus' | 'enterprise'
  users.subscription_id                → Stripe subscription ID
  users.subscription_start_date        → When plan starts
  users.subscription_end_date          → When plan ends
  users.plan_active                    → true | false

Get latest valuation for a startup:
  SELECT * FROM valuations WHERE startup_id = ? AND is_latest = true;

Get all 6 methods for a valuation:
  SELECT * FROM valuation_methods WHERE valuation_id = ? ORDER BY method_name;

Get startup's valuation history (trend):
  SELECT blended_weighted_average, created_at FROM valuations
  WHERE startup_id = ? ORDER BY created_at DESC LIMIT 12;

Get user's startup count:
  SELECT COUNT(*) FROM startups WHERE user_id = ? AND status = 'active';

Get pending email sequences:
  SELECT * FROM email_sequence_leads
  WHERE day_3_sent_at IS NULL AND day_3_scheduled_for <= NOW();

Get user's current subscription:
  SELECT plan, plan_active, subscription_end_date FROM users WHERE id = ?;

Get reports for a startup:
  SELECT * FROM reports WHERE startup_id = ? ORDER BY created_at DESC;
